# APIUYTIN surface direction

## Scope

Operate surface for the dashboard, documentation, project overview and OAuth chooser. The visitor is either a developer operating credentials or an end user making a consent decision. Vietnamese is the primary reading language.

## Product truth

Preserve the existing endpoints, IDs, data attributes, forms, copy actions, project actions, theme switch, mobile navigation, consent flow and OAuth contract. Do not expose secrets in browser UI or change backend behavior.

## Direction contract

### THESIS

APIUYTIN is a calm identity registry that makes the path from project to callback legible in one glance. It refuses the category-default dashboard made from anonymous floating cards and loud marketing gradients; every surface should show what can be operated, read or approved next.

### OWN-WORLD

The visual world is a modern registry desk: deep charcoal or warm paper grounds, hairline dividers, quiet off-white text, one terracotta signal color and restrained green/amber/red state colors. Be Vietnam Pro carries Vietnamese reading and headings; a compact system monospace is reserved for URLs, IDs, code and timestamps. Panels use flat surfaces, measured 12px corners and one clear elevation rule. The signature is a thin “identity route” line with small state nodes, used sparingly in dashboard project details, docs flow steps and consent context.

### STORY

The developer sees the platform state first, then the projects and their two server-side credentials, then the exact next action. The documentation reads like a reliable field manual with a stable reading rail. The end user sees who is asking, which callback receives the result, which remembered account will be shared and the two choices that complete or stop the decision.

### FIRST VIEWPORT

At desktop, a narrow left workspace rail names APIUYTIN and groups dashboard, projects, overview and resources. A quiet top command bar holds the current workspace, theme control and account state. The first screen uses a two-column 12-unit composition: a concise Vietnamese product statement and primary action on the left; a real OAuth redirect snippet and live health endpoint on a dark code surface on the right. The project section begins with a clear title, create-project action and the project list. At mobile, the rail becomes the existing bottom dock and drawer, the top bar stays compact, the copy stacks before the code surface, and primary controls remain at least 44px.

### FORM

Code-led replacement visual world, grounded in the seventh own direction: a registry desk with a route-marker signature. The shell stays a familiar web dashboard; the registry contributes only type, palette, density and the route line, never fake paper controls or a literal ledger. ## Success checks

- No horizontal overflow at 375/390/768/1024/1440px.
- Long documentation keeps a readable measure and a visible active section.
- Theme, copy, create/edit/revoke/rotate, account chooser, focus, Escape and reduced motion remain functional.
- Visual changes do not alter API routes, form names, IDs or data attributes used by scripts.
